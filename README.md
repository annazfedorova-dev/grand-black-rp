# Grand Black RP — онлайн-версия

3D RP-игра в браузере. Город Черноречье, валюта ПД, онлайн с друзьями на одном сервере.

## Что внутри
- `public/index.html` — сама игра.
- `server.js` — сервер: отдаёт игру и связывает игроков онлайн (WebSocket).
- `package.json` — описание проекта для хостинга.

## Как запустить в интернете (Render, бесплатно)
1. Залей эту папку на GitHub (новый репозиторий → Add file → Upload files → перетащи всё содержимое папки).
2. Зайди на render.com → войди через GitHub.
3. New → Web Service → выбери свой репозиторий.
4. Настройки:
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
5. Нажми Create Web Service и подожди 1–3 минуты.
6. Сверху появится ссылка вида `https://grand-black-rp.onrender.com` — её и отправляй друзьям.

Бесплатный сервер засыпает через 15 минут без игроков; первый вход после этого грузится ~1 минуту.

## Запустить у себя на компьютере
`npm start`, потом открыть http://localhost:3000
